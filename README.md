# birdlog_app_webversion

`birdlog_app` を元にした独立した Flutter Web / PWA アプリです。元のネイティブ版を変更せず、このフォルダだけを別のリポジトリとして利用できます。バックアップ・クラウド同期・ログイン機能は追加していません。

## 機能

- トリップ、鳥名・個体数・コメント・時刻・位置情報の記録と編集・削除。
- 定点モード、種のみ記録、よく見る鳥、種別集計、テキストのコピー。
- 地図・航空写真、種フィルタ、凡例、座標編集の表示。
- トリップを開いたとき・アプリに戻ったときに自動で測位を開始。画面を隠すと測位を停止します。
- 鳥名・個体数・時刻はGPSを待たずに保存します。10秒以内・誤差20m以内の位置があれば同時に保存し、なければ位置情報なしで保存します。保存後は最大30秒間、位置の候補を取得し、通知の「位置を追加」を押した場合だけ付けます。移動した場合は追加せず、編集画面から観察地点を指定してください。
- 行動・軌跡の記録機能は削除しました。旧版の軌跡データは互換性のため端末内に残しますが、読み込み・表示・追加はしません。
- IndexedDB に観察記録を保存。追加・変更・削除されたデータだけをトランザクションで保存します。書き込み失敗を保存成功として表示しません。
- 日本鳥類目録第8版の並び順は元アプリを継承。

## オフライン

初回は HTTPS（開発時は localhost）で開き、「オフライン利用の準備ができました」が表示されるまで通信を維持します。アプリ本体と日本語フォントが保存され、その後は圏外でも起動・記録・編集・集計できます。

地図は事前ダウンロードしません。オフライン時に見えるのはメモリやブラウザの通常HTTPキャッシュに残っている範囲だけです。キャッシュの期限・容量・配信元・ブラウザにより表示できない場合もあります。背景地図を取得できなくても観察記録は保存できます。

GPSの精度・取得可否は端末とブラウザに依存します。ウェブ版ではバックグラウンド連続測位を提供しません。位置情報の許可はブラウザのサイト設定で変更します。

設定の「保存状態を確認・永続保存を要求」で永続保存の許可状況と使用量の概算を表示します。永続保存の許可はブラウザが判断します。サイトデータを手動削除すると観察記録も消えます。同時編集による上書きを防ぐため、同一ブラウザでは1つのタブで使ってください。

Safari/iPhoneでは共有メニューの「ホーム画面に追加」、Chromeではインストールメニューを使います。インストールはオフライン準備完了とは別なので、準備完了の表示を確認してください。

## 起動・ビルド

Flutter 3.44.0 / Dart 3.12 以降、Python 3 を使用します。

```sh
flutter pub get
flutter analyze
flutter test
python3 tool/build_pwa.py
python3 -m http.server 8080 --directory build/web
```

`http://localhost:8080` を開きます。`index.html` のダブルクリック（file URL）では動作しません。

開発中の画面確認は `flutter run -d chrome` も利用できますが、PWA検証には上記のリリースビルドを使います。`flutter build web` だけでは独自Service Workerが生成されないため、必ず `tool/build_pwa.py` を実行してください。

サブディレクトリに公開する場合：

```sh
python3 tool/build_pwa.py --base-href=/birdlog_app_webversion/
```

## GitHub Pages

1. **このフォルダの中身**を、新しい `birdlog_app_webversion` リポジトリのルートに配置します（`.github` を含む）。
2. GitHub の Settings → Pages → Source を **GitHub Actions** にします。
3. `main` ブランチにpushすると同梱のワークフローがテスト・ビルド・公開します。

この作業ではGitHubへのpush・公開は行っていません。元のリポジトリのサブフォルダに置いたままでは、このフォルダ内のGitHub Actionsは自動認識されません。

更新版はバックグラウンドで準備し、記録中に強制再読み込みしません。アプリのタブをすべて閉じてから開くと新しい版になります。更新時にIndexedDBを削除しません。公開ドメインを変更すると保存領域が変わります。

## ウェブ版での変更

- 画面・モデル・鳥名配列・保存処理を別ファイルに分離。
- ネイティブ用SQLite、古いネイティブ版からの移行処理、iOSの権限チャンネル、バックグラウンド設定、デバッグ用データを削除。
- 保存は全テーブルの削除・再挿入をやめ、変更分のみ保存。
- 地図画像のメモリ上限を256MiBから64MiBに縮小。
- 端末の住所検索機能はウェブ非対応のため、手動の字名取得ボタンは国土地理院の逆ジオコーダーへ置換。日本国内が対象で、検索時に座標を送信します。結果を端末にキャッシュし、連続リクエストに間隔を設けています。サービスの応答・提供範囲・CORSに依存し、利用できないときも観察記録は残ります。

## 外部リソースと出典

- 地図・航空写真は元アプリの配信元を継承。地図上に出典を表示。[OpenStreetMapタイル利用方針](https://operations.osmfoundation.org/policies/tiles/)。オフライン用の事前取得はしません。
- 字名・自治体名：[国土地理院 地理院地図](https://maps.gsi.go.jp/) の逆ジオコーダーと `js/muni.js`。[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)。地名は位置の正確な所属を保証しません。
- 日本語表示：[Google Fonts Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp)、[SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/notosansjp/OFL.txt)。初回起動時に配信元から取得し、アプリのオフラインキャッシュに保存します。初回取得に失敗するとオフライン準備は完了しません。

アプリ本体のキャッシュ更新は観察データと分離されています。PWAのキャッシュ削除処理は、このアプリの配信パスに対応する古いアプリキャッシュだけを対象にします。

## 検証

- `flutter analyze`：指摘なし。
- `flutter test`：記録の先行保存、復帰時の測位、位置追加の確認、種のみ、定点、集計、地図操作を検証。
- 検証用Chrome：スマートフォン幅での起動、IndexedDB保存、複数ストア更新の失敗時ロールバック、同時編集の防止、通信を切っての再読み込み、記録の保持を確認。
- GitHub Pagesと同様のサブパス `/birdlog_app_webversion/` で確認。
- iPhone/Safariの実機測位とホーム画面へのインストールは未検証。

実ブラウザの検証は、Node 22以降とChromeがある環境で `node tool/browser_smoke.mjs` を実行します。専用の一時プロファイルを作り、普段のブラウザデータは使いません。Chromeの場所は `CHROME_PATH` 環境変数で指定できます。
